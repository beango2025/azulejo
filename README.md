# Azulejo

一款从 **A1 到 C2** 的欧洲葡萄牙语（português europeu, pt-PT）学习应用。名字来自葡萄牙街头随处可见的彩绘瓷砖 *azulejo*。

**在线版：** [beango2025.github.io/azulejo](https://beango2025.github.io/azulejo/)

课程不只有语法表：每个级别都配有 **情景视频 + 音频对话**，词汇以 **葡 / 中 / 英 / 法 / 西** 五种语言对照。

> **PT-PT only**：课程、词汇、练习、影音和外部资源都使用欧洲葡语。文化文章里会出现巴葡对比，但只用于解释差异，不作为学习目标；外部资源页不收录巴葡项目。

## 现在可以做什么

- **6 个 CEFR 级别：A1 → C2，每个级别 30 节课**，共 14 个单元、180 节课；**180 个场景标题全部唯一**，从「No aeroporto, à chegada」到「Numa feira do livro」，练习课也不重复核心课的场景。
  - A1 入门：9 节核心课 + 21 节练习课。
  - A2 日常：9 节核心课 + 21 节练习课。
  - B1 叙事与生活：6 节核心课 + 24 节练习课。
  - B2 论证与科技：6 节核心课 + 24 节练习课。
  - C1 艺术与社会：6 节核心课 + 24 节练习课。
  - C2 修辞与翻译：6 节核心课 + 24 节练习课。
  - 每节练习课都是完整的 5 题训练（听辨、词汇、造句、翻译、对话、语音或综合），不是占位内容。
- **12 个影音练习**：每个级别 1 个 **情景视频（vídeo-cena）** + 1 段 **音频对话**。
  - 视频是可播放的插图动画场景：人物、对白气泡、字幕、时间轴、播放/暂停、逐句跳转、重复、速度与字幕开关。
  - 音频练习有波形、双人/三人对话、隐藏字幕、逐句脚本，以及可切换角色的 **role-play** 模式。
  - 每段影音结束都有 3 道理解题，完成可获得 XP。
- **6,188 个五语词汇**：葡萄牙语、中文、English、français、español 对照，可按 A1–C2 筛选、五语搜索、逐词听音。
- **5 种互动练习**：选择、听力、拼写、词序、配对。
- **间隔复习（SRS）**：按 `Outra vez / Difícil / Bem / Fácil` 安排下次复习。
- **1000 句场景口语句型**：20 个真实场景 × 50 句；配中文、English、français，支持场景筛选、四语搜索和收藏。
- **100 篇葡萄牙文化讲解**：10 个主题 × 10 篇；每篇配中文、English、français 三种完整讲解。
- **5 个 PT-PT 外部资源入口**：Falar、Fala Bem、PTptIndex、EP Spoken Frequency、Conversas com Amália；在「文化 → Recursos externos」里直接跳转，全部经过 pt-PT 筛选，不含巴葡项目。
- **每节课自己的阅读、听力和口语**：`Leitura & escuta` 步骤为每课提供考试长度短文、4 道阅读理解题、整篇听力（1.5–6 分钟）和一句角色跟读；另保留同级别视频/音频对话入口。
- **CAPLE 难度与篇幅**：阅读和听力按葡萄牙国家考试 CAPLE 的级别与文本长度设计；不是三五句的短句堆叠。

| 课程级别 | CAPLE 对应 | 阅读正文长度 |
|---|---|---:|
| A1 | 预备 CIPLE | 140–180 词 |
| A2 | CIPLE | 180–230 词 |
| B1 | DEPLE | 280–340 词 |
| B2 | DIPLE | 420–500 词 |
| C1 | DAPLE | 550–650 词 |
| C2 | DUPLE | 700–850 词 |

听力使用同一篇完整文本朗读，时长随级别约 1.5–6 分钟；语法点、词汇和题型按对应级别控制。级别对应参考葡萄牙 CAPLE 考试：CIPLE（A2）、DEPLE（B1）、DIPLE（B2）、DAPLE（C1）、DUPLE（C2）；A1 为进入 CIPLE 前的预备级别。官方信息：[caple.letras.ulisboa.pt](https://caple.letras.ulisboa.pt/)。
- **独立阅读入口**：顶部「阅读」栏目按 A1–C2 列出全部 180 个阅读场景，点击卡片直接跳到该课的阅读步骤，不需要先过单词和语法。
- **每级 10 篇听力**：编号独立为 `A1.1`–`A1.10`、`B1.1`–`B1.10`，共 60 篇；场景各不相同，支持 `0,6×–1,4×` 滑杆调速（播放中改速会从新速度重播），进度按单篇记录。
- **短剧配音**：6 个视频场景支持字幕、逐句录音、回放、发音匹配和语速评分；分数单独保存在对应场景。
- **听力原文 + 中文翻译**：60 篇听力都带完整葡语原文和逐段中文翻译。
- **6,188 个五语词汇**：A1–C2 六级分级（A1 1,100 / A2 886 / B1 955 / B2 1,040 / C1 1,059 / C2 1,148 条），PT / 中 / EN / FR / ES 五语对照。词汇表按**名词、动词、形容词、副词、短语**分组，每条带三位连续序号和分组词数。
- **动词变位表**：120 个核心动词 × 7 个时态 × 6 个人称；`语料 → 动词` 中展开查看。
- **独立语法库（句法 + 词法）+ 课文内讲解 + 每课练习 + 记忆钩子**：56 个语法章节，A1–C2 筛选、句法/词法切换、搜索、葡语例句配中文、英文解释、章节练习和上下章导航。词法覆盖名词、冠词、形容词、副词、动词变位组、时态体、代词、介词、连词、数量词、指小词、构词法、话语小词和复合词；每篇阅读后有「Gramática no texto」并链接对应章节，语法页另配 12 条记忆法。
- **Escrita 写作（在模考 Pro 下面）**：A1–C2 每级 50 道原创写作题（共 300 题），随机抽题，支持粘贴或上传 `.txt`，本地四维评分，配置 `writingApiUrl` 后可接 AI 评分。侧栏入口在「模考 Pro」之后，Pro 页模拟卷下方也有写作入口。
- **考试与大纲**：CAPLE A1–C2 考试介绍、CL/PIE/CO/PIO 四项构成，按级别把功能大纲和 56 个语法章节对应起来。
- **B1–C2 每课双阅读**：阅读列表每课只有一个小标签（如 B1-1），点进去再选 **B1-1-A 泛读** 或 **B1-1-B 精读**；A 是本课阅读，B 是本课 + 同级别关联文本的双文本精读，配 22 个本级词、6 个语法点和理解题。
- **每日 10 分钟（Rotina diária）**：5 个词 + 1 个语法点 + **一整段视频场景逐句跟读评分**（按视频原长度，不是固定一句）+ 2 道题 + 7 天进度报告；完成得 XP，并接入复习队列。
- **学习语言选择**：设置里可选中文 / English / Français / Español / Português；导航、按钮、筛选标签切换语言，词汇表高亮所选语言列，英语模式下语法讲解优先显示英文，暂缺翻译回退中文/English。
- **语料 → 主题词与形容词**：10 个配图场景（咖啡馆、市场、交通、住房、健康、工作、学校、旅行、城市、文化）PT/ZH/EN/FR/ES 对照；形容词按性质、大小、颜色、情绪、状态、国籍分类。入口在「语料」的词汇标签内，不再占用侧栏。
- **每篇课文后的单词表**：每篇 **15 个本级词汇**（不会把 A1/A2 基础词塞进 C1/C2），优先取文中词，文本太短时从同级别词库补齐；按名词 / 动词 / 形容词 / 副词 / 短语分类，配中文、English 和发音。每课另有 **2 道词汇题 + 1 道词法题**。
- **Azulejo Pro / 分级模考**：60 套完整模拟考试，A1–C2 每级 10 套。**按级别单独购买**：买 A2 只解锁 A2 的 10 套，不捆绑其他级别。每套覆盖阅读、听力、写作、口语，带计时、成绩报告和错题解释。
- **销售与运营配置**：`js/config.js` 填支付链接/联系方式；`tools/make-license.mjs` 生成签名许可证；内置本地事件埋点，可接分析端点。
- **可选账号 + 云同步**：Supabase 邮箱登录；学习后自动上传，换设备手动拉取；不登录仍使用本地模式。
- **A2 原生 PT-PT 音频**：10 篇 A2 听力改为 Microsoft `pt-PT-RaquelNeural` 神经语音 MP3；听力页支持原生音频变速，A2 模考听力使用原生播放器。注意：这是神经语音，不是真人录音棚录音。
- **静态 SEO 页面**：独立于 hash 路由的 134 个可收录页面（A2 CIPLE、100 篇文化、20 个场景、1000 句），带 canonical、Open Graph、JSON-LD、sitemap 和 robots.txt。
- **课文真实照片**：阅读页按场景显示 1 幅**里斯本**真实照片（28 路电车、Pastéis de Belém、Mercado da Ribeira、Bertrand Chiado、Parque das Nações、Assembleia da República、Torre de Belém、法朵、azulejo 外墙、药物博物馆、Praça do Comércio）。全部来自 Wikimedia Commons，授权与作者见 [assets/photos/CREDITS.md](assets/photos/CREDITS.md)。

## 影音说明

为了实现完全本地、无版权依赖的影音练习，视频采用 **浏览器内 SVG/CSS 动画场景**，语音采用 **Web Speech API**。它不是预先录制的 MP4，而是一个带时间轴、对白调度、字幕和角色状态的“动画情景视频”播放器。音频对话同样由浏览器朗读，并可切换两个葡萄牙语声音（如果系统安装了 pt-PT 语音）。

在支持 `speechSynthesis` 的 Chrome / Edge 中体验最好。没有葡语语音时，播放器仍可用字幕和阅读脚本完成练习。

## 打开方式

### 在线版

直接打开：

```
https://beango2025.github.io/azulejo/
```

### 本地服务器

双击 `启动应用.bat`，浏览器会自动打开：

```
http://127.0.0.1:8788
```

或者在当前目录运行：

```bash
node server.js
```

Node.js 仅用于启动静态服务器，应用本身没有构建步骤、没有 npm 依赖。

### 直接打开

也可以直接双击 `index.html`。课程、影音、词汇、复习和本地进度都能使用；PWA 安装和 Service Worker 需要 `http://` 环境。

## 五语词汇

每个词条都有：

- 葡语原形 / 短语
- 中文释义
- English gloss
- français
- español
- 简化发音（给中文母语者的记忆辅助，不是 IPA）
- 级别、例句、使用提示

在「语料 → 词汇」中可以按语言搜索，例如输入 `heteronym`、`inquiétude`、`异名者`，都会定位到同一个词。

## 版本号与更新提示

当前版本：**v3.30.0**。

- 顶栏、侧栏底部和「设置」里都会显示当前版本号。
- 当本地记录的版本号与 `APP_VERSION` 不一致时，打开应用会弹出 `Azulejo atualizado para vX.Y.Z` 提示。
- 更新版本时需要同时修改：`js/app.js` 的 `APP_VERSION`、`sw.js` 的 `CACHE`、`manifest.webmanifest` 的 `version`，并在 [CHANGELOG.md](CHANGELOG.md) 记录。

![版本更新提示](screenshots/version-update.png)

## 进度与数据

所有进度保存在浏览器 `localStorage` 的 `azulejo.state.v1` 中，不上传服务器，也不需要账号。包括课程完成度、XP、连续学习、复习间隔、影音完成记录和收藏。

- 换浏览器、清理站点数据或使用无痕模式会丢失进度。
- 「进度」页面底部或「设置」里可以清空全部进度。

## Azulejo Pro 配置

网站不绑定支付服务商，先把商业参数填到 `js/config.js`：

```js
window.AZ_CONFIG = {
  checkoutUrl: 'https://buy.stripe.com/...', // 或 Lemon Squeezy / Gumroad
  contactUrl: 'https://your-wechat-or-booking-link',
  supportEmail: 'you@example.com',
  analyticsEndpoint: '', // 可选：接收 sendBeacon 事件
  examApiUrl: '', // 可选：私有题库 Worker /exam-bank
  levelPrices: {
    A1: { eur: '€9,99', cny: '¥69' },
    A2: { eur: '€14,99', cny: '¥99' },
    B1: { eur: '€19,99', cny: '¥139' },
    B2: { eur: '€24,99', cny: '¥179' },
    C1: { eur: '€29,99', cny: '¥219' },
    C2: { eur: '€34,99', cny: '¥259' }
  },
  checkoutUrls: { A1: '', A2: '', B1: '', B2: '', C1: '', C2: '' }
};
```

推荐流程：

1. 在 Stripe / Lemon Squeezy / Gumroad 分别创建 **A1 / A2 / B1 / B2 / C1 / C2** 六个商品，每个 10 套。
2. 把每个支付链接填入 `checkoutUrls[level]`，把客服/微信/预约链接填入 `contactUrl`。
3. 用户付款后，按级别生成许可证：

```bash
node tools/make-license.mjs --email aluno@example.com --level A2 --days 365
```

4. 把输出的 A2 许可证发给用户；用户选择 **A2 → Licença** 粘贴激活。

每个许可证只解锁对应级别的 10 套。`--plan pro` 仅用于内部测试或历史全量许可，不作为对外商品。

`.secrets/license-private.pem` 用于签发，已在 `.gitignore` 中排除，不要上传或发给用户。

### 自动支付 + 自动发证

仓库包含一个 Cloudflare Worker 模板：[server/README.md](server/README.md)。

流程：

1. 每个级别的 Stripe Payment Link 设置 metadata：`level=A1` / `A2` / …，成功页设为 `https://beango2025.github.io/azulejo/#/pro/success`
2. Stripe webhook 指向 Worker 的 `/stripe-webhook`
3. Worker 验证签名，用私钥签发该级别许可证
4. Resend 把许可证邮件发给用户

部署：

```bash
cd server
npx wrangler deploy
npx wrangler secret put STRIPE_WEBHOOK_SECRET
npx wrangler secret put LICENSE_PRIVATE_KEY < ../.secrets/license-private.pem
npx wrangler secret put RESEND_API_KEY
npx wrangler secret put FROM_EMAIL
```

当前应用本身仍可离线验证许可证；Worker 只负责自动交付。账号与云同步见下一节；退款自动化还没有接。

## 授权、隐私与侵权检查

应用内有 **Créditos, licenças e privacidade** 页面（`#/legal`），说明：

- Wikimedia Commons 照片的作者、CC BY / CC BY-SA 授权与裁剪后的相同方式共享要求。

### 私有题库 API（可选）

`server/worker.js` 已包含 `GET /exam-bank`：

- 校验 `Authorization: Bearer <许可证>`
- 从 Cloudflare KV `EXAM_BANK` 返回完整题库
- 只接受未过期的签名许可证

启用步骤见 [server/README.md](server/README.md)。简版：

```bash
node tools/export-exam-bank.mjs
npx wrangler kv namespace create EXAM_BANK
npx wrangler kv key put bank --binding=EXAM_BANK --path=server/exam-bank.json
npx wrangler secret put LICENSE_PUBLIC_JWK
```

然后在 `js/config.js` 设置：

```js
examApiUrl: 'https://<worker>.workers.dev/exam-bank'
```

启用后，App 会在激活许可证时拉取私有题库；如果接口失败，仍回退到本地题库。

**重要**：Git 历史仍保留已提交的 `js/exam-bank.js`。要让题库真正不可下载，需要把仓库设为私有，或在发布前重写 Git 历史；仅删除当前文件不够。

## 静态 SEO 页面

应用主体是 hash 路由的 PWA，搜索引擎难以收录。因此另生成一套纯静态页面：

- `/seo/` — 总入口
- `/sitemap.xml`、`/robots.txt`

内容更新后重新生成：

```bash
node tools/build-seo.mjs
```

生成器会重写 `seo/` 下的页面、`sitemap.xml` 和 `robots.txt`，但保留 `seo/seo.css`。上线后在 Google Search Console 提交：


注意：静态页面里的 CTA 会跳回 PWA 的 `#/` 路由；SEO 页面只负责被搜索到和转化，课程交互仍在 PWA 里。

## 内容范围

课程按 CEFR 的日常与学术场景编写，语法点包括：

- `ser` / `estar` / `ficar`，反身动词与代词后置
- `estar a + 不定式`，`ir + 不定式`
- 未完成过去时 vs 简单过去时
- 条件式与 `se + imperfeito do conjuntivo`
- 正式邮件语体、让步与条件从句
- 名词化、无人称 `se`、被动语态
- 文学语体、反讽、习语与语域

内容为独立编写的学习材料，不是官方教材。真实语言有很多地区差异，遇到不同说法时，优先观察你所在城市和对话对象的习惯。
